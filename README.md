# dsa-practice

Haftalık veri yapıları ve algoritma çalışmalarım. Her dosya bir konuyu ve çözümleri içerir.

## İçindekiler

| Hafta | Konu | Dosya |
| 1 | Two pointers | `week1_two_pointers.py` |
| 2 | Sliding window | `week2_sliding_window.py` |

## Çalıştırma

```
python week2_sliding_window.py
```

Yalnızca standart Python gerekir (3.10+).

## Notlar
- `iki_toplam_siralı`: sıralı dizide iki uçtan daralan iki pointer, O(n).
- `yinelenenleri_sil`: yavaş ve hızlı pointer ile yerinde silme, O(n).
- `max_sum`: sabit pencere, O(n).
- `en_kisa_alt_dizi`: değişken pencere, O(n).
- `en_uzun_tekrarsiz`: iki pointer ve set, O(n).
